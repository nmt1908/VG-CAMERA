# ============================================================
# SUPER SCRIPT: SETUP MÁY CHUYÊN DỤNG VG-CAMERA (DEVICE OWNER)
# Cách này giúp app có toàn quyền vĩnh viễn, không bị hệ thống thu hồi.
# ============================================================

# ----- 1. GỠ CÀI ĐẶT BẢN CŨ (ĐỂ TRÁNH XUNG ĐỘT) -----
adb uninstall com.example.vgcamera

# ----- 2. CÀI ĐẶT BẢN MỚI -----
# Lưu ý: Thay đổi đường dẫn đến file APK nếu cần
adb install "/home/gmo044/Desktop/Android Studio Source/VG-CAMERA/app/release/app-release.apk"

# ----- 3. THIẾT LẬP DEVICE OWNER (QUẢN TRỊ VIÊN TẨM CAO) -----
# QUAN TRỌNG: Phải xoá hết tài khoản Google/Email trong Cài đặt trước khi chạy lệnh này.
adb shell dpm set-device-owner com.example.vgcamera/.DeviceAdminReceiver

# ----- 4. CẤP QUYỀN QUẢN LÝ TẤT CẢ TỆP (SILENT GRANT) -----
# Quyền này giúp app dọn rác và truy cập bộ nhớ không cần hỏi user.
adb shell appops set com.example.vgcamera MANAGE_EXTERNAL_STORAGE allow

# ============================================================
# GHI CHÚ:
# - Sau khi chạy xong 4 lệnh trên, app sẽ tự động có quyền Camera, Mic, GPS... 
#   ngay khi mở lên nhờ chính sách AUTO_GRANT đã cài trong code.
# - Sau khi xong, anh có thể đăng nhập lại tài khoản Google bình thường.
# ============================================================
